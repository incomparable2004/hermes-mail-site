Hermes Mail Tool

A personal, single-user mail assistant.

What it does

Hermes Mail Tool is a private, locally-run helper that reads, searches, labels and organises the owner's own email mailbox. It runs entirely on the owner's own computer and is used by one person only.

How it uses Google data

When connected to a Google account, it uses the Gmail API with the gmail.modify and gmail.send scopes to list messages, read message contents, apply or remove labels, archive conversations and send mail on the owner's behalf. Data is processed only on the owner's device and is never transmitted to any third party, sold, or used for advertising.
