Privacy Policy

Hermes Mail Tool · Last updated: October 2026

1. Who this covers

Hermes Mail Tool is a personal, non-commercial tool operated by a single individual (the “owner”) on their own computer. It is not offered as a service to the public and has no other users.

2. What data is accessed

With the owner's explicit consent, the tool accesses the owner's own Gmail mailbox through the Gmail API, limited to these scopes:

  • https://www.googleapis.com/auth/gmail.modify — read messages and manage labels (mark read/unread, archive, move to trash).
  • https://www.googleapis.com/auth/gmail.send — send email on the owner's behalf.

This includes message headers, message bodies, attachment names and labels belonging to the owner's account only.

3. How data is used

Data is used solely to display, search and organise the owner's own email and to send mail the owner requests. No automated profiling, advertising, or analytics is performed.

4. How data is stored and protected

OAuth tokens are stored locally on the owner's computer in a file readable only by the owner's user account (file mode 0600). Message contents are processed in memory and are not copied to any external server. The tool does not maintain its own database of message content.

5. Sharing and disclosure

No data is sold, rented, traded, or shared with any third party. Data is never used to train machine-learning models and is never transferred to advertisers or data brokers. Google user data is not used for any purpose other than the ones disclosed above, in line with Google's Limited Use requirements.

6. Retention and deletion

Because no external copy of mailbox data is kept, there is nothing to retain. The owner may revoke access at any time at Google Account permissions; deleting the local token file immediately ends all access.
